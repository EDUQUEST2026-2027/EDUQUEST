🔒 Politique de confidentialité

Principe fondamental : vos données restent sur votre appareil

EDUQUEST fonctionne intégralement dans votre navigateur (mode local) : aucune donnée personnelle n'est envoyée à un serveur, ni revendue, ni partagée. Tout ce que vous saisissez (pseudo, mot de passe, progression, réglages) est enregistré uniquement dans le stockage local (localStorage) de votre navigateur, sur cet appareil.

Données traitées et finalités

Choix de consentement cookies Mémoriser votre décision (12 mois, recommandation CNIL) localStorage (clé eduquest_cookie_consent) 12 mois

Mot de passe

Le mot de passe des comptes locaux est haché avant d'être stocké : il n'apparaît jamais en clair dans le navigateur. Ce mécanisme reste léger (protection locale) : pour un usage en établissement avec de vrais comptes, activez le mode API SQL où la gestion des comptes et des mots de passe est assurée par un serveur sécurisé.

⚠️ Mode API : si l'éditeur active le mode API SQL (API_URL dans db.js), les données de comptes et de progression transitent alors vers le serveur correspondant. Dans ce cas, cette politique doit être complétée avec l'identité de l'hébergeur, la base légale et la durée de conservation côté serveur, avant toute mise en ligne.

Absence de partage

Aucun service tiers n'est sollicité : pas de réseau publicitaire, pas de réseau social, pas d'outil de statistiques. La seule requête externe éventuelle est le chargement des polices de caractères (Google Fonts) par les feuilles de style ; aucune donnée de jeu ne lui est transmise.

📜 Vos droits

Le RGPD vous accorde des droits d'accès, de rectification, d'effacement, de portabilité et d'opposition sur vos données personnelles. Dans EDUQUEST, vous les exercez directement depuis l'application :

  • Accès & rectification : connectez-vous et ouvrez la page « Options », ou demandez à l'administrateur (panneau → onglet « Membres »).
  • Effacement : l'administrateur peut supprimer un compte depuis le panneau (onglet « Membres »). Pour effacer toutes les données de cet appareil, effacez les données de site du navigateur ou utilisez la réinitialisation dans le panneau (onglet « Réglages »).
  • Portabilité : la configuration d'administration est exportable en JSON (panneau → onglet « Réglages »).
  • Réclamation : vous pouvez saisir la CNIL (cnil.fr) si vous estimez que vos droits ne sont pas respectés.
